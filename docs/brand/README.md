# Brand assets

Two files belong here, and the repository README links the first one:

| File | What it is |
|---|---|
| `wordmark.png` | The "ToDoTrip" lettering, teal on a transparent background. Used at the top of the repository README. |
| `icon.png` | The 512×512 app icon: a white T on the brand teal. |

They are not in the repository yet — drop the two images you have into this
folder under exactly those names and the README picture starts working.

`icon.png` is also what a launcher icon would be generated from, if the app ever
stops using the Flutter default.
